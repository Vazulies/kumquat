How it works

Three keys. Zero windows.

Kumquat waits quietly in the tray. It only shows up when you're already moving a file somewhere.

1 · Start dragging

From your file manager, the desktop or any app that drags files. Several files at once work too.

2 · Tap a key

A wheel opens under your cursor. Switch wheels any time while you're still holding the file.

⇧ ShiftCtrlSpace

3 · Drop on a choice

The result lands where you were dragging to. The original is never touched or overwritten.

Why Kumquat

Open source. Made for Linux and Windows.

The best drag-and-convert tools have been Mac-only and paid, often with a limit on how many files you can convert. Kumquat brings the idea to the rest of us, with the code in the open.

Kumquat is released under the MIT license: use it, change it, ship it in your own projects. Read every line, build it yourself, fork it and send fixes. There's no account, no license key, no counter of free conversions and no telemetry.

FAQ

Questions, answered.

Is it really free?

Yes. Kumquat is open source under the MIT license, so you can use it for anything, including commercial work. There's no paid tier, no trial and no limit on how many files you convert.

Are my files uploaded anywhere?

No. Every conversion and edit runs on your own computer with tools bundled inside the app. Kumquat works with your network switched off.

Where do converted files go?

Where you were dragging to. Tap the key over the desktop and the result appears at that spot; over a folder window, it's saved in that folder; anywhere else, next to the original. Nothing is ever overwritten, and half-finished files never show up.

Can I change the keys?

Yes. Shift, Ctrl and Space are the defaults, and each wheel can use any of them in Settings. Space is the default for actions because Alt+Shift switches keyboard layouts on many systems.

Does it work on Wayland?

Wayland doesn't let apps see other apps' drags, so the drag wheel needs an X11 session. On Wayland you can still select files and press F4 in your file manager, or use Choose files… from the tray icon.

Can I use it without dragging?

Yes. Select files in your file manager and press F4 (or use the right-click menu), then pick with the arrow keys and Enter. Tab switches between formats, tools and actions.

How can I help?

Report bugs, suggest formats, translate, or send a pull request on GitHub. Stars help other people find the project too.
